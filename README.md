# Aurea Engine

Aurea Engine is a primarily 3D-focused game engine inspired by engines from the late 1990s and early 2000s, particularly Unreal Engine 1.5.

A lot of elements are also inspired by Godot, however no code is lifted or forked from Godot.

Currently, I am refactoring code from a previous private build that got rather messy.

To see what I am currently focusing on, check out [Milestones](https://github.com/mocacola02/AureaEngine/milestones).
